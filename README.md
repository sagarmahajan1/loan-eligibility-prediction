# 🏦 Loan Eligibility Prediction App

This is a **Streamlit app** that predicts whether a loan will be approved or not based on applicant details like income, loan amount, credit history, property area, and more.  

The app is built using **XGBoost** and trained on real-world loan datasets.  

---

## 🚀 Live Demo

Try the app here: [Loan Status App](https://loan-statusapp.streamlit.app/)

Or use the badge:  
[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://loan-statusapp.streamlit.app/)

---

## 📝 Features

- User-friendly interface with Streamlit  
- Takes applicant details (income, loan amount, education, property area, etc.)  
- Shows instant **Loan Approved / Not Approved** result  
- Encodes categorical data automatically  
- Built with **XGBoost** for accurate predictions
